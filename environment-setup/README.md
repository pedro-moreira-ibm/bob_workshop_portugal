# Environment Setup

Use this folder for the shared environment preparation steps referenced by the workshop labs.

For this workshop, the recommended provisioning path is the [Agentic AI Bootcamp TechZone bundle](https://ibm.biz/tz-agenticAI-camp), which includes the core services used across the exercises:

- watsonx.ai
- Cloud Object Storage (COS) and watsonx.ai Runtime
- watsonx Orchestrate
- IBM Code Engine
- Container Registry
- watsonx.governance

## Getting Started

1. [Create your IBMid](create-IBMid.md)
2. [Access your class instance](access-env.md)
3. [Create your Cloud API key](api_key_setup.md)
4. [Set up a watsonx project](create-project.md) if your use case requires watsonx.ai
